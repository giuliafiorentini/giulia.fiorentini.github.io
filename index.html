Come ricevere davvero i file degli studenti?

Questo sito è fatto solo di file statici: non ha un server che salva i compiti. Quindi:

  • Le pagine Consegna e Suggerimenti funzionano in modo anonimo sul PC dello studente (generano codice anonimo + file da scaricare).
  • Per raccogliere tutto tu, crea un Modulo Google anonimo (senza raccolta email) e incolla il link nelle due pagine.
  • Istruzioni pronte nelle pagine: sezione gialla “Come consegnare”.
